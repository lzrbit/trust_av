# Inputs and data rules

`derived_schema.json` lists the actual expected field names and dtypes, not records. Supply `participants.parquet`, `events.parquet` and `windows.parquet` in the configured input directory. `describe` also requires `source_participants.parquet` for the original cohort-flow summary. The builder generates these from an authorized copy of the exact source workbook. No original or derived participant dataset is shipped.

- `participant_id` is a stable within-study key. The original builder uses source Excel row numbers; these remain sensitive linkage keys and must not be published.
- Participant rows include age, years holding a licence, self-reported country, categorical driving/automation experience and six pre/post attitude items. Country describes the survey's reported country field, not a representative national sampling frame. Age and licence duration use the survey's 2023 reference year. Gender/education and experience categories must retain the original coding.
- `events` has a unique `event_row_id`, a participant key, scenario block, `event_key`, assigned event ID, `risk_event_mean` and coverage denominators. Event means use available operated clips and can be partial.
- `windows` has a unique `window_row_id`, participant/event keys, `window_index`, `risk_raw`, `risk` and missingness flags. Only video risk 0 means no slider operation and is missing in risk analyses; pre/post attitude 0 is valid. Values 1–10 are retained. The sixth LC position is defined; other scenarios have five positions. Do not fabricate unassigned event rows or a sixth clip for other scenarios.
- The primary sample retains all completed/licensed respondents and all 29 reported countries. Duration flags are sensitivity indicators, not primary exclusion rules. Small-country precision remains limited; no sample-size filter is applied.

Internal block labels are B1=LC, B2=SVM, B3=HB, B4=MB. `data/event_design.csv` contains 105 **stimulus-design** rows, not participant records; its source Excel row refers to the parameter workbook. It is the author-confirmed design mapping and the analysis uses design-assigned factor levels. LC events 19–24 have a known distance-label/trajectory discrepancy; the primary design analysis and exclusion sensitivity remain separate. HB events 7–9 have a discrepant stored acceleration channel, so groups use the design braking intensity verified against velocity changes. These caveats are not erased by the label confirmation.

`config/risk_column_mapping.json` is the original survey-column map (question identifiers and indices only). It contains no answers, names or respondent IDs. `data/aggregate` contains the 6-row pre/post summary, 24-row performance summary 15-row HB box summary and 15-row HB paired-test family. Individual flier lists are excluded. Counts and confidence intervals are study aggregates and do not support national representativeness or causal claims.
