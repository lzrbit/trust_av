# Methods retained in the public implementation

**Profiles and uncertainty.** Average operated event ratings within participant and clip, then weight participants equally. Participant resampling preserves repeated observations. The controlled-factor analysis uses 2,000 shared participant multinomial draws for the full 189-profile set, 75 paired contrasts and additive fixed-effects sensitivity. Primary paired contrasts are marginal over other factors, not matched on them. The 75-contrast fixed-bootstrap-SE maximum standardized deviation gives a simultaneous sensitivity interval; pointwise intervals are not interchangeable with it. Fixed-effects fitting uses categorical main effects, participant intercepts and total weight 1 per participant. It is exploratory, excludes interactions, and does not establish causal parameter effects.

**Prediction.** All preprocessing/tuning uses training data. Participant 5-fold, leave-country-out, event-group 5-fold and crossed participant/event 5×5 holdouts address different targets. Identity-only and identity-plus-person comparators use matching splits. Scores pooled over event rows and person-weighted summaries answer different questions. Performance intervals condition on the fitted models and realized stimulus library; they do not include refit or new-stimulus uncertainty. Country is retained including singleton countries, without invented within-country precision.

**Explanations.** Held-out TreeSHAP uses stable row keys, path-dependent attribution and the model's expected value. Actual interaction values are computed, not inferred from point colors. Off-diagonal pair contributions are doubled when displaying an unordered pair. Family signed sums and mean absolute feature contributions are distinct summaries. Correlated age/experience attribution is model-dependent; no causal interpretation follows.

**Trust.** Pre/post 0 values remain valid. Changes use paired post-minus-pre values. The differential outcome is `(post LKS − pre LKS) − (post ACC − pre ACC)`; its OLS/HC1 associations compare participants, although the outcome is constructed within each participant. This model is not held-out prediction. Separate post-task trust models use training-fold risk features. Cross-outcome contrasts retain the covariance between outcomes.

**What-if.** Fixed participant-held-out pipelines are evaluated at explicitly supported pre-task item values. Neighbors are unique training participants, never held-out participants. Local Gower support, range limits, shared eligible sets, a 12-comparison simultaneous interval and threshold sensitivities are retained. An unsupported joint perturbation is not a zero effect. Sensitivity is associational/model-conditional, not an intervention effect.

**HB annotation.** Fifteen two-sided paired-mean t tests (three braking-level pairs × five clips), Holm correction across all 15, and pointwise t intervals are a new post hoc family, separate from the 75 bootstrap contrasts. Stars concern means, not medians. Available participants can differ by pair. Boxplot whiskers are the most extreme observed participant mean inside 1.5 IQR; fliers are retained in all calculations.

The old source-run inventory checks, revision-to-revision assertions and manuscript assembly audits are not scientific estimators and are not bundled. Portable replacements hash current input files and check them for changes. The repository is analysis code plus a small aggregate release, not a complete raw-data release or a claim of prospective preregistration.
